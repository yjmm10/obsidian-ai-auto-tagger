## 改用 Vercel AI SDK（真正的多厂商统一库，替代官方 openai SDK）
- 用户纠正：「支持各大厂商 + 兼容 OpenAI 接口的开源库」不是官方 `openai` SDK（后者只认 OpenAI 协议端点），而应选统一接口的多厂商库。经确认采用 **Vercel AI SDK**（`ai` + `@ai-sdk/openai-compatible` + `@ai-sdk/anthropic` + `@ai-sdk/google` + `zod`，均 MIT）。
- 新增 `AIProvider` 类型：`"openai-compatible" | "anthropic" | "google"`；`AISettings.provider` 字段；移除原 `useJsonMode`（generateObject 自动处理结构化输出）。
- ai-client.ts 重写：`buildModel()` 按 provider 构造语言模型（openai-compatible 兼容 OpenAI/DeepSeek/通义/智谱/豆包/Ollama；anthropic 原生 Claude；google 原生 Gemini）；`callAI` 改用 `generateObject` + 动态 zod schema；`verifyConnection` 改用 `generateText`；自建 `timeoutSignal`(AbortController) 实现超时；`describeError` 适配 AI SDK 的 `statusCode` 等。
- settings.ts：新增「厂商 / 接口类型」下拉；移除「使用 JSON 模式」开关；Base URL 说明按 provider 区分必填/可选；模型名示例补充 claude/gemini。
- README 同步更新：功能特性、配置表、工作原理。
- 验证：`npm install` 成功（openai 已移除），`ai` 升至 v5.0.210 以匹配 providers 的 V2 模型接口；`maxTokens`→`maxOutputTokens`，`buildModel` 返回 `any`，`generateObject` 的 schema 强转 `any` 避免深度类型推断；`npm run build` 通过（tsc + esbuild），main.js 1.1M，三个 provider 均打包进 bundle（openai-compatible / anthropic / google）。
